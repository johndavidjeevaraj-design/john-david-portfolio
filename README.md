# John David — Minimal Sci-Fi Portfolio

A minimal, editorial portfolio for a creative technologist. Built with Next.js App Router, React and TypeScript. No icon library, component library, card UI or animation runtime is required; the orbital hero artwork and motion are CSS-driven.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Customize

- Edit project content and capabilities in `components/portfolio.tsx`.
- Edit colors, typography, layout and motion in `app/globals.css`.
- Update metadata in `app/layout.tsx`.

The project URLs and profile links are based on details supplied by the owner. Add a LinkedIn URL and a downloadable resume when available.
